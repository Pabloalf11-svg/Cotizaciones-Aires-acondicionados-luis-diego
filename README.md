# Cotizador · Aires Acondicionados Luis Diego

Sistema para crear cotizaciones y descargarlas en PDF para enviar al cliente.

## Uso
Abrí `index.html` en el navegador (Chrome o Safari), o activá GitHub Pages:
**Settings → Pages → Branch: `main` / `(root)` → Save**.

## Funciones
- Datos del cliente, lista de aires acondicionados y servicios, cantidades y precios
- Descuento, IVA 13 %, colones o dólares
- PDF con logo, número de cotización, fecha, vigencia y condiciones
- Nombre del archivo editable al descargar
- Historial de cotizaciones y datos de la empresa (se guardan en el navegador)
- Modo claro / oscuro

Hecho con HTML, CSS y JavaScript (jsPDF + jsPDF-AutoTable).
